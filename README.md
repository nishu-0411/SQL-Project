# Travel Agency Management System — SQL

A SQL-based **Travel Agency Management System** designed to manage and analyze travel-related data.

## 📌 About the Project

This project uses a relational database to manage different aspects of a travel agency, including:

* Customers
* Bookings
* Travel Packages
* Destinations
* Hotels
* Transport
* Payments
* Travel Insurance
* Feedback
* Offers
* Tour Schedules
* Guides
* Employees

## 🛠️ Technologies Used

* SQL
* Relational Database Management
* CSV datasets

## 🔍 SQL Concepts

The project covers:

* Database & table creation
* Primary & Foreign Keys
* Data insertion and manipulation
* Filtering and sorting
* Aggregate functions
* `GROUP BY` and `HAVING`
* Joins
* Subqueries
* Data analysis

## 🎯 Purpose

The goal of this project is to demonstrate how SQL can be used to **design, manage, and analyze a relational database for a real-world travel agency**.
